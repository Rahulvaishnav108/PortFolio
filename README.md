# PortFolio

Static personal portfolio website for Rahul Vaishnav.

## Available files

- `index.html` — main portfolio page
- `styles.css` — page styling
- `script.js` — scroll animations and nav effects
- `package.json` — local static server setup

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the site:
   ```bash
   npm start
   ```
3. Open the local URL shown in the terminal.

## Notes

- Add a `profile.jpg` image file in the project root to display your profile photo.
